PACK DIAGNOSTIC MFINANCES - MODE D'EMPLOI RAPIDE

Fichiers :
- GUIDE-WEBMASTER-DIAGNOSTIC-MFINANCES.docx : le guide complet.
- diagnostic-mfinances-snippet.html : le bloc HTML à copier dans la page Tarifs.
- diagnostic-mfinances.css : le style visuel.
- diagnostic-mfinances.js : la navigation et le calcul du résultat.
- maquette-reference-mobile-v4.html : maquette complète de référence.
- maquette-reference-desktop-v4.html : maquette complète de référence.

Ordre recommandé :
1. Faire une sauvegarde de la page Tarifs actuelle.
2. Charger le fichier CSS.
3. Copier le snippet HTML après l'infographie de progression et avant les cartes tarifaires.
4. Charger le fichier JavaScript avec l'attribut defer.
5. Vérifier que les ancres #basic, #essentiel, #premium et #excellence existent.
6. Tester les quatre résultats et l'affichage mobile.
7. Ne publier qu'après validation sur une page de test.

Important : la maquette V4 sans JavaScript a été conçue pour être testable dans un lecteur de fichier.
Pour le site réel, la version JavaScript fournie dans ce pack est plus simple à maintenir.
