# Pack MFINANCES — À propos + Notre organisation

Ce ZIP contient les maquettes HTML desktop/mobile ainsi que le dossier complet d'implémentation SEO/GEO pour le webmaster.

## Structure
- `01-MAQUETTES-HTML/` : 4 fichiers autonomes de prévisualisation, tous en `noindex,nofollow` par sécurité.
- `02-SEO-GEO/` : metadata, JSON-LD, patch sitemap, patch robots, llms.txt recommandé et plan de maillage.
- `03-WEBMASTER/` : note d'implémentation détaillée, snippets React/Vite et checklist QA.

## Règle essentielle
**Ne pas publier quatre pages.** Le site final doit avoir seulement :
- `https://mfinances.be/a-propos/`
- `https://mfinances.be/notre-organisation/`

Chaque URL doit être responsive et combiner le rendu desktop/mobile présenté dans les maquettes.

Commencer par lire `03-WEBMASTER/NOTE-WEBMASTER.md`.
